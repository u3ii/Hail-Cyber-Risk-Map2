References and Data Sources

Frameworks and vulnerability databases

The project draws on publicly available references for threat intelligence, cybersecurity guidance, and municipal service information. Each source serves a distinct role in the analysis.

National Cybersecurity Authority (NCA) Reference for cybersecurity controls and frameworks National Vulnerability Database (NVD) Reference for published vulnerability information CISA KEV Catalog Reference for confirmed exploited vulnerabilities Digital Government Authority (DGA) Reference for digital government frameworks

These references are used to support threat analysis and terminology. They are not live data integrations. The asset data shown within the platform is illustrative and intended for modeling purposes.
